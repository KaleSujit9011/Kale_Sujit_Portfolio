#  Sujit Kale — Portfolio

A modern, performant developer portfolio built with **React 19**, **Vite 8**, and **Tailwind CSS 4**.  
Showcasing projects, experience, skills, and a contact flow — with dark/light theme support and glassmorphism UI.

## ✨ Features

- 🌓 **Dark / Light theme** toggle with saved preference
- 🎨 **Glassmorphism UI** with glow effects and gradient text
- ⚡ **Animated hero** with rotating role text
- 🃏 **Project cards** with preview image, live demo, and GitHub links
- 🪜 **Ladder-style experience** timeline
- 🏷️ **Filterable skills** section with animated skill chips
- 📧 **Contact form** that opens a prefilled email draft
- 🔗 **Footer** with portfolio navigation and social links
- 📱 **Fully responsive** layout for desktop, tablet, and mobile
- ⏱️ **Loading screen** with smooth animated transition

##  Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/KaleSujit9011/Kale_Sujit_Portfolio.git
cd Kale_Sujit_Portfolio/portfolio

# Install dependencies
npm install
```

### Development

```bash
# Start the dev server
npm run dev
```

### Production

```bash
# Create a production build
npm run build

# Preview the production build
npm run preview
```

### Linting

```bash
npm run lint
```

##  Contact Form Note

The contact form uses a `mailto:` link, opening the visitor's email app with a prefilled message. For production form submissions without email-client dependency, connect the form to a backend API or a form service like [Formspree](https://formspree.io/) or [EmailJS](https://www.emailjs.com/).
